# Kevin-the-escape-cube
Gilde project challenge : making an escape room/object


**Order of operations

Steps: 
1 startcode, derived from fysical puzzle. (timer starts)
2 figure out "water flow" through potentiometers.
3 when 2 is correct. A hidden drawer containting puzzle pieces opens. 
4 pieces from step 3 are used to connect a circuit.
5 when 4 is correct, dot matrix maze turns on. playable by gyroscope.
